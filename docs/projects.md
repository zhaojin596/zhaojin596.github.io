# 项目

这里汇总我在课程学习中的实践项目，覆盖机器学习、智能控制、嵌入式、机器人、大模型应用与工业控制等方向。每段写明背景、思路与成果；报告与 PPT 已归档，GitHub 仓库链接陆续补充中。

## 大三秋冬

### 工业磨损预测（大数据解析与应用导论）

- **简介**：Kaggle 赛题，基于声学信号的设备磨损状态分类。完成数据清洗与标准化后，分别采用 1D-CNN 端到端学习、XGBoost 手动特征工程、STFT 频谱图 + CNN 三条路线建模并对比，处理维度灾难、域偏移与复杂信号等难点。
- **技术栈**：Python、PyTorch、XGBoost、STFT 频谱分析
- **状态**：已完成
- **链接**：[GitHub 主页](https://github.com/zhaojin596)（仓库待补充）

## 如何添加新项目

复制上面任意一个项目的格式，从 `###` 标题开始新写一段，保持「简介 / 技术栈 / 状态 / 链接」四行信息完整即可。有演示截图或图表时，把图片放到 `docs/public/` 目录，用下面的语法插入：

```md
![项目截图](/project-name.png)
```
